Исследование сетевого трафика, анализ сетевых соединений и формирование пакетов с использованием Wireshark и Scapy.

## Цель проекта

Изучить методы анализа сетевого трафика и исследования сетевых артефактов с использованием Wireshark и Scapy.

В рамках проекта исследованы SMB-соединение и признаки Reverse Shell в предоставленных дампах трафика, а также реализовано формирование TCP-пакета с помощью Python и Scapy с последующим захватом и анализом переданных данных.

## Контекст

Работа выполнялась с использованием предоставленных сетевых дампов и локального окружения для формирования и анализа пакетов.

## Окружение и инструменты

| Инструмент | Назначение |
|---|---|
| Wireshark | Анализ сетевого трафика и исследование пакетов |
| Python | Разработка скрипта для формирования пакета |
| Scapy | Создание и отправка сетевых пакетов |

## Ход работы

Подробное описание выполнения заданий, анализ результатов и скриншоты представлены в [техническом отчёте](docs/report.md).

### 1. SMB Traffic Analysis

- Исследован предоставленный дамп сетевого трафика `task1.pcap`.
- Определена версия SMB-диалекта — SMB 3.1.1.
- Изучены параметры установленного SMB-сеанса.
- Определены Session ID и участвующая в соединении учётная запись.
- Исследованы MAC-адреса взаимодействующих устройств.

### 2. Reverse Shell Investigation

- Исследован дамп `some_troubled_traffic.pcapng`.
- Обнаружен подозрительный TCP-сеанс между узлами `192.168.1.101` и `192.168.1.100`.
- Определены направление соединения и используемые TCP-порты.
- Исследовано содержимое TCP Payload и обнаружены переданные команды и связанные с ними ответы.

В ходе анализа обнаружены команды `id`, `uname -a`, `whoami`, `ls -la /etc` и `cat /etc/passwd`.

### 3. Scapy Packet Crafting

- Разработан Python-скрипт с использованием библиотеки Scapy.
- Сформирован IP/TCP-пакет с заданным текстовым сообщением.
- Использован адрес назначения `127.0.0.1` и TCP-порт `12345`.
- Выполнен захват сформированного пакета с помощью Wireshark.
- Исследованы заголовки пакета и переданные данные.

## Анализ сетевой безопасности и применение в SOC

| Технология / навык | Применение |
|---|---|
| SMB Analysis | Исследование сетевых соединений и параметров SMB |
| NTLMSSP | Анализ процесса аутентификации |
| TCP Stream Analysis | Исследование содержимого TCP-соединений |
| Reverse Shell Detection | Поиск признаков удалённого командного взаимодействия |
| Packet Analysis | Исследование заголовков и полезной нагрузки пакетов |
| Scapy | Формирование и автоматизация работы с сетевыми пакетами |

Полученные навыки применимы при анализе сетевых событий, поиске подозрительной активности, исследовании сетевых артефактов и расследовании инцидентов информационной безопасности.

- Изучено содержимое TCP-сеанса и выявлены переданные команды.
- Разработан Python-скрипт для формирования сетевого пакета с помощью Scapy.
